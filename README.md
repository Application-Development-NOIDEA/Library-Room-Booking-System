# Library Room Booking System

A web-based application designed to simplify library room reservations and improve room management for university students and library staff.

## 📌 Project Overview

The **Library Room Booking System** provides a centralized platform for students to book library carrel rooms, discussion rooms and meeting rooms without having to visit the library counter physically.

The system allows students to check room availability, make reservations, manage bookings and report facility issues. It also provides library staff with a management dashboard to monitor reservations, room occupancy and student feedback.

An integrated **AI-Powered Report Analyzer** helps summarize student-submitted reports and identify recurring facility issues, supporting better library maintenance and service improvements.

## ✨ Key Features

### 1. Room Booking Management
- View available carrel rooms, discussion rooms and meeting rooms.
- Check real-time room availability.
- Select preferred dates and time slots.
- Make reservations through a centralized platform.
- Prevent double bookings and scheduling conflicts.

### 2. QR Code Check-In and Check-Out
- Generate a unique QR code after booking confirmation.
- Allow library staff to scan the QR code for booking verification.
- Record student check-in and check-out times.
- Automatically cancel bookings if students fail to check in within 15 minutes of their reservation time.

### 3. Booking Reminders
- Send automated reminders 30 minutes before the reservation.
- Send checkout reminders 15 minutes before the scheduled checkout time.
- Help students keep track of their reservations.

### 4. Waiting List and Booking Extension
- Allow students to join a waiting list when rooms are fully booked.
- Notify students when a room becomes available.
- Allow students to request booking extensions if no subsequent reservation exists.

### 5. AI-Powered Report Analyzer
- Allow students to submit facility-related feedback and complaints.
- Use AI to automatically summarize submitted reports.
- Identify recurring facility issues, such as broken lamps and damaged furniture.
- Help library staff identify areas requiring maintenance and improvement.

### 6. Staff Management Dashboard
- Manage student reservations.
- Monitor room availability and occupancy.
- Verify student check-ins and check-outs.
- View and manage facility issue reports.
- Access AI-generated report summaries.

## 👥 User Roles

| User Role | Responsibilities |
|---|---|
| Student | Book rooms, manage reservations, check in/out and submit feedback. |
| Library Staff | Verify QR codes, monitor room usage and manage reservations and reports. |
| Administrator | Manage system information, staff access and AI-generated report summaries. |
